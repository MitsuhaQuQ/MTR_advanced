# i18n.js

高级编辑器各页面的翻译词典与翻译函数。页面文字用简体中文书写，`tr()` 在这里查其他语言的译文，查不到则原样保留；`{0}`、`{1}`… 用参数填入，`{{`、`}}` 表示字面花括号。`trc()` 用于某处需要不同译法的词，以 `"上下文\u0004文字"` 为键查找。语言在页面收到游戏数据（其中的 `language` 字段）后跟随游戏，在此之前用游戏上次使用的语言或浏览器语言；任何地区的中文显示简体中文原文；没有词典的语言显示英文。普通脚本，声明全局绑定 `I18N`、`tr`、`trc`、`translatedList`（非 `globalThis` 属性）。旧页面（`index.html`、`audio.html`）和新页面（`editor-web/index.html`，经 `editor-web/src/i18n.ts` 按名字读取 `I18N`）都先于主脚本加载它。新页面的新文字也加在这里（中文键 → 英文）。

## `I18N`（IIFE 返回的对象）
### 内部
- `DICTIONARIES`：语言代码 → 词典（中文原文 → 译文）。目前只有 `en_us`（第 15 行起，约 1600 条，含新旧页面的文字）。
- `STORAGE_KEY = "mtr-editor-language"`：`localStorage` 中记住的语言。
- `pick(code)`：规整语言代码（小写、`-` 换 `_`）：空或 `zh` 开头 → `zh_cn`；有词典的 → 自身；否则 `en_us`。
- `stored()`：读 `localStorage` 中的语言（不可用时 null）。
- `language`、`dictionary`：当前语言（初值 `pick(stored() || navigator.language)`）及其词典（`zh_cn` 为空对象）。
- `format(text, args)`：填参数。
- `translate(text, args)`：词典中有 `text` 则用译文，再 `format`。
- 加载时监听 `DOMContentLoaded`，对整个文档 `applyStatic`。

### 公开成员
- `language`（getter）：当前语言代码。
- `translate(text, args)`：见上。使用者：本文件 `tr`/`trc`、`editor-web/src/i18n.ts`。
- `setLanguage(code)`：记住 `code`（写 `localStorage`），语言变化时换词典并 `applyStatic(document)`。返回是否变化。调用者：`editor.js:684`（读到游戏数据时）、`media.js:192`、`editor-web/src/i18n.ts`（`state/store.tsx:74`）。
- `applyStatic(root)`：设置 `<html lang>`，并翻译 `root` 下带 `data-i18n`（文本）和 `data-i18n-title` / `data-i18n-aria-label` / `data-i18n-placeholder`（属性）的元素，属性值为中文原文。调用者：本文件；`editor-web/src/legacy/stage.ts:26`、`editor-web/src/legacy/stage.ts:27`（经 `i18n.ts`）。

## 全局函数
- `tr(text, ...args)`：翻译并填参数。旧页面各脚本和本文件大量使用。
- `trc(context, text, ...args)`：先查 `context\u0004text`，查不到（返回原键）再查 `text`。
- `translatedList(list)`：返回一个 Proxy：按数字下标读取时每次都翻译（用于常量中的名称列表）。调用者：`editor.js:24`、`editor.js:25`（星期名）。

## 维护约定（来自 CLAUDE.md）
- 网页编辑器的文字加在本文件（中文键 → en_us）；值中不要用 `"`。

# StationFlows.tsx

全网图里点车站弹出的车站股道运用图（0.80.0）。由 `NetworkSchematic` 在选中车站时显示（取代原来的车站卡片；找不到车站数据时仍显示卡片）。

- 轨道画成灰色（站台粗），两个方向都有车走的轨道加红底。
- 每条线在每段轨道上画一条沿运行方向流动的虚线（`<animate>` 改 `stroke-dashoffset`，系统设了减少动态时不动），线路颜色；几条线同向共用一段轨道时虚线段轮流排开，直接叠加；运用走行画成细点线；每段轨道每个方向在中点画一个箭头。
- 顶栏：范围（80/160/300/600 格）、"运用走行"开关、在实际图上看、关闭（也可按 Esc）。底栏图例：点一条线只显示它，再点恢复；右侧写两个方向都有车走的股道段数。
- 测试：`test/stationFlows.test.tsx`（每种用法一条流动线、图例只显示一条线、Esc 关闭）。

# core/schematicLayout.ts

对 `TrackMap`（`core/trackSchematic.ts`）做的另一种示意化：把横竖方向不同的两个车站之间的主干拉成"直—45° 斜角—直"的 L 形，附近的轨道和道岔像一条带子一起移动。`src` 中未找到调用者（可能是保留的试验实现或仅测试使用，未确定）。

## 内部工具
- `length(points)`：折线长度。
- `equal(a, b)`：两点是否重合（1e-6）。

## 导出
### `schematicLayout(input)`
- 输入 `TrackMap`，返回 `TrackMap & { trunks: number[] }`（`trunks` 为被拉直的轨道序号）。不修改输入。
- 步骤：
  1. 建邻接表：只把 `kind === 0` 的轨道作为可走的边；站台轨道（`kind === 1` 且有 `station`）的端点记为车站节点及其方向（竖/横）。
  2. 从每个车站节点做 Dijkstra（按轨道长度），到达另一车站、且两站方向不同时记一条候选主干（每对车站保留最短的）。
  3. 用并查集分连通分量。候选按长度从短到长处理：跳过与已用轨道重叠的、点数少于 3 的、横纵跨度较小者小于 80 的、首尾方向与 L 形拐角相反的。
  4. 目标形状 `[a, before, after, b]`：拐角在 `(a.x, b.y)`（竖向起点）或 `(b.x, a.y)`，拐角处切一个最长 32 的 45° 斜角。
  5. `transform(p)`：把点投影到原路径上（得到沿路径距离、侧偏、越出量），按比例映射到目标折线上相同位置并保持侧偏；离路径越远（影响范围 `support = max(160, 跨度×1.5)`）移动权重越小，超出范围不动。
  6. 同一分量中的轨道、尽头、分岔点、车站名位置都按 `transform` 移动；已锁定的点不动。两端都在路径 40 以内的轨道记为已用并锁定其点。

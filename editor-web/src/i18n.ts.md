# i18n.ts

新页面的翻译入口。`assets/mtr/editor/i18n.js`（普通脚本，与构建出的页面放在同一文件夹，不打包）在 `index.html` 里先于本页脚本加载，它用 `const I18N` 声明一个全局绑定（不是 `globalThis` 的属性），本文件按名字读取它：文本按简体中文书写，再去词典里查英文等。测试环境里没有加载 i18n.js 时，文本保持中文，只做 `{0}` 占位替换。新页面新增的文字也要加进 i18n.js（附英文）。

## 类型
- `Dictionary`（内部）：i18n.js 中 `I18N` 对象的形状：`language`（当前语言代码）、`translate(text, args)`、`setLanguage(code)`（返回是否切换成功）、`applyStatic(root)`（翻译静态 DOM）。
- `declare const I18N`：声明全局绑定，可能为 `undefined`。

## 内部函数
- `dictionary()`：返回 `I18N`，未加载时返回 `undefined`（用 `typeof` 判断，避免 ReferenceError）。
- `format(text, args)`：无词典时的回退格式化：`{0}`、`{1}`… 换成 `args[i]`，`{{`/`}}` 转义为 `{`/`}`。返回字符串。
- `translate(text, args)`：有词典走 `I18N.translate`，否则 `format`。

## 导出
- `tr(text, ...args)`：翻译并填参数。全页最常用，例如 `core/dispatch.ts:121`、`state/store.tsx:11`、`views/StopsEditor.tsx:194`。
- `trc(context, text, ...args)`：带上下文的翻译：先查键 `context + "\u0004" + text`，查不到（返回原键）就退回查 `text`。对应 i18n.js 的 `trc`。调用者：`core/model.ts:52`（星期分隔符）、`core/dispatch.ts:121`（列表分隔符）。
- `setLanguage(code)`：切换词典语言，返回布尔值；无词典返回 `false`。副作用：改变 `I18N` 的当前语言。调用者：`state/store.tsx:74`（服务器数据里带来的 `language`）。
- `applyStatic(root)`：让词典翻译 `root` 下带静态标记的 DOM 文本。调用者：`legacy/stage.ts:26`、`legacy/stage.ts:27`。
